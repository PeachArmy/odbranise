# Зора

Тивка, статична страница со информации за жени во Северна Македонија. Нема аналитика, колачиња, сметки, формулари ниту барања кон други страници додека некој сам не стисне линк или „Брз излез“.

Името **Зора** е привремено. Се менува на едно место: `brand` во [`src/config/site.ts`](src/config/site.ts). Логото го чита оттаму.

`<title>` е ист на секоја страница (`documentTitle` во истата датотека) за јазичето и историјата да не го кажуваат предметот. Ако името подоцна стане описно, остави го `documentTitle` неутрално.

## Cloudflare Pages

Нема тајни и нема променливи за приклучување. Поврзи го складиштето во Cloudflare Pages со овие поставки:

| Поле | Вредност |
| --- | --- |
| Framework preset | Astro |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Root directory | `/` |
| Node.js version | 22 |
| Environment variable | `NODE_VERSION` = `22` |
| Environment variables / secrets | нема |

`npm run build` ја гради страницата и потоа пушта `scripts/check-build.mjs`. Ако се појави туѓ URL, скрипта, формулар или број што не е на проверениот список, градбата паѓа.

Датотеката `public/_headers` оди во `dist` и Cloudflare ја применува: без упатувач, без рамки, строга политика за содржина, без складирање на HTML.

Остави ги **исклучени** овие опции на Cloudflare, инаку се додава туѓа или вметната скрипта:

- Web Analytics
- Email Address Obfuscation
- Rocket Loader
- Bot Fight Mode и I'm Under Attack

Не додавај адаптер за сервер. Страницата е само статични датотеки.

## Јазик

Во верзијата 1 е само македонски, на коренот, без префикс `/mk`. Текстовите се во:

- `src/i18n/mk/` — реченици, броеви, страницата „Сокриј ги трагите“
- `src/content/articles/mk/` — статии во Markdown

За албански подоцна: ископирај го `src/i18n/mk/` во `src/i18n/sq/`, преведи, додај го јазикот во `src/i18n/index.ts` и во `locales` во `src/config/site.ts`, па додај Markdown во `src/content/articles/sq/` со `lang: sq`. Буквите ë и ç веќе се во фонтот. Рутите за вториот јазик сè уште не се вклучени.

## Статии

Нова статија е нова датотека `.md` во `src/content/articles/mk/` со наслов, опис, `lang`, `order`, `slug` и `draft: true`. Не пишувај бројки, статистики или телефон што го нема во проверениот список. Додека е нацрт, на страницата пишува „Наскоро“.

## Броеви

Не додавај број што не е јавно проверен. Изворот за 20.11.2026 е во `src/i18n/mk/contacts.ts`. Кога ќе провериш одново, смени ги бројот, `verifiedOnLabel` во `src/config/site.ts` и списокот во `scripts/check-build.mjs` во иста измена.

## Брз излез

`quickExitUrl` во `src/config/site.ts` е страната што се отвора. Копчето и две брзи притискања на Escape ја повикуваат `location.replace`, за Назад да не ја врати страницава. Без JavaScript копчето е обичен линк кон истата адреса.

## Фонт

Nunito е подмножество (латиница и кирилица), само на нашиот домен, со лиценцата SIL OFL во `public/fonts/OFL.txt`. Нема повик кон Google Fonts.

## Приватност

Нема аналитика, пиксели, колачиња, формулари, сметки ниту служба за следење. Не вклучувај такво нешто подоцна.
